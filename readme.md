# 🎓 Student Management System

A Python-based Student Management System designed to manage student records, teacher information, and academic grades through a web-based interface.

## 🚀 About The Project

This is my **first personal project**, with the entire backend logic independently developed by me using Python and Object-Oriented Programming (OOP).

The frontend interface was designed with AI assistance to visually represent the functionality of the backend as a website.

## ✨ Features

- 🎓 **Student Registration** – Register students with personal details.
- 👨‍🏫 **Teacher Registration** – Maintain teacher information.
- 📊 **Grade Management** – Add and update student grades.
- 📋 **Student Records** – View and search student details.
- 👥 **Teacher Records** – Access registered teacher information.
- 📈 **Dashboard** – View student statistics and academic summaries.
- 💾 **Data Persistence** – Store records using JSON.

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone https://github.com/PritamCodesStudio/Student-Management-System.git
```

**2. Navigate to the project folder**

```bash
cd Student-Management-System
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run app.py
```
